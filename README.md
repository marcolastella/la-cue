# La Cue — sito

*Diamo il LA. · Ready to Cue.*

Sito narrativo di **La Cue**, il cue player per chi va in onda (macOS).
HTML, CSS e JavaScript puri, nessuna libreria: funziona così com'è su GitHub Pages.

## Struttura
```
index.html
assets/
  style.css        identità: palette, Bodoni Moda, Space Grotesk, JetBrains Mono
  main.js          animazioni a scorrimento e parallasse
  fonts/           i font inclusi nell'app
  icon-512.png     icona ufficiale (dall'app)
  favicon.png, apple-touch-icon.png
```

## Pubblicare su GitHub Pages
1. Crea un repository (es. `la-cue-site`) e carica tutto il contenuto di questa cartella.
2. **Settings → Pages** → *Deploy from a branch* → `main` / `(root)`.
3. Il sito sarà su `https://USERNAME.github.io/la-cue-site/`.

Live: https://marcolastella.github.io/la-cue/
